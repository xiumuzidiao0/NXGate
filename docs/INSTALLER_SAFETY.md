# 安装器行为与安全边界

适用于本次修复后的 `main/install.sh`。这次仅修复部署与终端管理脚本；应用版本仍为 `2.6.5.12`，没有移动既有标签或重建既有 Release。

## 运行和输入

推荐先下载、检查脚本，再在交互式 SSH 终端以 root 运行：

```bash
curl -fL https://raw.githubusercontent.com/xiumuzidiao0/NXGate/main/install.sh -o install.sh
less install.sh
bash install.sh
```

有控制终端时 `curl | bash` 也能显示提示并正确读取输入；没有控制终端时停止，不把管道中的脚本文本当成答案。密码输入前关闭回显，正常读取、EOF 或信号退出时恢复终端设置。安装完成的凭据摘要仍会显示密码，请勿公开截图或日志。

安装器先检查正在运行的 systemd，再收集参数。配置确认默认 `N`：按回车取消，不写配置、不安装系统依赖。无 systemd 的 OpenRC Alpine/普通容器应采用独立进程或仓库的 Docker Compose 配置，不会安装依赖后才发现不支持服务管理。

## SSH、防火墙和路由

脚本不自动修改 SSH 端口放行规则、不添加 `ip rule`，也不插入绕过 UFW/firewalld 的 iptables 规则。状态查询不再迁移目录、下载自愈二进制或重启服务；服务命令只执行明确指定的操作。

NXGate 后台和本地代理保持默认回环监听，远程管理推荐 SSH 隧道或带认证和有效证书的 HTTPS 反向代理。确实需要对外提供服务时，由管理员核对实际监听地址，在正在使用的防火墙和云安全组中明确设置来源、端口及协议；脚本不替你全来源开放端口。

旧版安装器可能已写入 SSH 放行规则和优先级 50 的策略路由。本次修复不会自动撤销它们：无法可靠区分管理员规则与旧脚本规则，自动删除可能中断现有连接。检查、移除前请保留另一条 SSH 会话及云控制台恢复通道。没有“绝不断 SSH”的保证。

## sing-box

首次安装默认跳过 sing-box。明确选择安装组件也不会自动创建入站；随后单独确认才会创建一次 VLESS-REALITY 入站。创建前会提示默认监听所有地址 `::`，可能对公网开放。控制访问来源，并自行验证客户端、出站、NXGate 代理认证与连通性；创建配置不等于已能访问互联网。已有 sing-box 配置保持原样；从管理菜单新建入站也需要确认公开监听。

## 下载与工具链

NXGate 发行二进制仍须匹配官方 SHA256SUMS；下载显示进度，最多 300 秒，持续低于 1 KiB/s 60 秒视为停滞。5 Mbps 带宽通常只是下载较慢，不会解释配置提示隐藏。

源码编译缺少合格 Go 时，从 `go.dev` 官方 JSON 元数据选择精确版本、Linux 架构及 archive 文件名，下载后先校验 SHA256，再隔离解压和检查工具版本。失败拒绝安装。备用工具链保存到安装目录的 `toolchains/go<版本>/`，仅用于本次构建的 PATH；不覆盖 `/usr/local/go`，不追加 `/etc/profile`。Go 下载最多 900 秒并有停滞检测。校验依赖 HTTPS 和官方元数据，不等同于独立签名验证。

sing-box 核心初装与随源码内嵌的管理下载共用相同策略（通过一致性测试保持同步，安装器不依赖外部 source 文件）：

- 每次请求最多 600 秒，建立连接最多 15 秒；持续低于 1 KiB/s 达 60 秒切源。正常慢速传输不再受旧 30 秒上限影响。配置覆盖：`NXGATE_DOWNLOAD_TIMEOUT=60..1800`、`NXGATE_DOWNLOAD_STALL=5..300` 秒；这两个变量仅作用于 sing-box 下载链路。
- HTTP 404、DNS/连接/TLS 错误、传输截断和超时立即尝试下一源；HTTP 429/500/502/503/504 等待 2 秒，只重试同源一次。每源最多两次，没有无限循环；不并发下载，不跨源续传。4 源的最坏预算不超过 `4 × (2 × TIMEOUT + 2)` 秒（默认约 80 分钟；仅临时服务错误会重试）。
- 显示下载进度、来源、curl 退出码、HTTP 状态及接收字节数；不再吞掉失败原因统一归咎网络。curl 28 表示超时或低速停滞，不能单凭它判断具体网络原因。
- 初装固定 v1.14.0 的四架构 SHA256，取自 SagerNet 官方 GitHub Release 资产的 digest 元数据；第三方镜像也必须符合该摘要，失败丢弃并切源。管理脚本更新其他版本时，须从官方 API 取得精确资产的 SHA256，否则停止；这会受 API 可用性/限流影响。仅校验成功后提取预期核心文件，不把任意 tar 路径解压到系统目录，不跳过 TLS 验证。
- 官方 amd64 压缩包为 31,639,897 字节，5 Mbps 理想下载约 51 秒，30 秒硬上限不足；实际耗时还取决于服务器到 GitHub/镜像的路径，不能保证某镜像在用户 VPS 可用。

初装修复直接随最新 `main/install.sh` 生效；已发布的旧 NXGate 二进制仍内嵌旧管理脚本。管理更新链路的改进须从本次源码重新构建、释放管理脚本或后续新版本才会生效，本次不自动替换服务器脚本/发布新版本。本次不是所有第三方脚本下载链路的完整供应链审计。

## 验证范围

`python3 scripts/tests/test_installer.py` 通过 PTY、临时目录与 mock 命令检查交互、无终端/EOF、取消、安全默认、单次创建、systemd 预检和 Go 校验/暂存。不会执行真实安装，不修改测试主机防火墙、路由或服务。`python3 scripts/tests/test_downloads.py` 使用回环 HTTP fixture 检查超过 30 秒的持续低速下载、404/503、连接拒绝、停滞、部分响应、错误校验和、预算参数和内嵌下载逻辑一致性。另有 CLI 配置回归、ShellCheck error 级检查与 Bash 语法检查。

这些检查不能替代 Debian VPS 上的真实部署、SSH 连接存续、真实公网入站和升级测试。未连接用户服务器，未撤销其已有规则。
